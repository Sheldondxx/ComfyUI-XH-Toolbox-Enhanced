# 🔁XH-滑块（Comfyui-XH_Slider）

Nodes 2.0 原生渲染的滑块节点，用来替代 `comfyui-mxtoolkit` 的 Slider（那个用 canvas 手绘，
Nodes 2.0 下渲染不出来，原作者仓库 2025-05 起已停更）。

## 安装

把整个 `Comfyui-XH_Slider` 文件夹放进你的 `ComfyUI\custom_nodes\` 目录，然后**完全退出并重启 ComfyUI**。

- 无需下载任何模型、无需安装 Python 依赖。
- 搜索节点：双击画布 → 搜「XH」→ `🔁XH-滑块`，分类 `🔁XH/Control`。

## 怎么用

| 位置 | 作用 |
|---|---|
| 滑块 / 右侧数值框 | 拖滑块或直接输入数值 |
| ⚙ | 展开「最小 / 最大 / 步进 / 小数位」四格设置 |
| 中 / EN | 中英文切换（与 XH 家族其他包共用同一语言状态） |

- **小数位 = 0** → 输出 `INT`；**小数位 > 0** → 输出 `FLOAT`（和原版 mxSlider 行为一致）。
  改小数位时，如果已连的线类型对不上会自动断开，重新连一下即可。
- 配置全部存在节点里，随工作流一起保存，不需要手动改任何参数框。

## 说明

- 数据存在折叠的 `slider_json` 参数里，你看不见也不用管它。
- 节点身体是标准 DOM 渲染（不是 canvas 手绘），Nodes 2.0 下不会有空白/错位问题。
