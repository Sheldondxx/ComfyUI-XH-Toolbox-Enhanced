# 🔊 音效库使用说明（就放在这里，方便你随时看）

这个文件夹是 **🔊XH-声音播放** 节点的音效库。
节点里的「音效文件」下拉选项，就是**实时扫描**这四个子文件夹生成的。

```
sounds/
├── ui/      提示音 —— 空的（想放提示音丢这儿）
├── sfx/     音效   —— 原子弹爆炸 / 狙击枪 / 道具出现 / 牛叫 / 狗叫 / 马叫 / 鸡叫 / 小女孩哈哈（8 个）
├── music/   音乐   —— 空的（想放背景音乐丢这儿）
└── voice/   人声   —— 海贼王路飞 / 主人 / 日语奶奶 / 孙悟空 / 葫芦娃爷爷 …（28 个）
```

## 怎么加自己的声音

1. 把音频文件**直接丢进**某一个分类文件夹里（比如 `sfx/`）。
2. 回到 ComfyUI 网页，**按 F5 刷新**。
3. 节点上的「音效文件」下拉里就能选到了。

支持格式：`wav` `mp3` `ogg` `flac` `m4a` `aac` `opus` `webm`

⚠️ **不用重启 ComfyUI** —— 只要 F5。
⚠️ 文件名用中文没问题（下拉里会显示成「音效 · 我的文件」，中文已验证可用）。
⚠️ 下拉默认选中的是**扫描列表的第一项**（当前 = `sfx/原子弹爆炸.flac`），加新文件后第一项可能变化，属正常。

## 分类怎么选

| 你想干的事 | 丢进哪个文件夹 |
|---|---|
| 「这一批跑完了」提示一下 | `ui/` |
| 画面里「嗖」一下、「哐」一声 | `sfx/` |
| 想要一小段背景音乐 | `music/` |
| 台词、角色配音、拟人叫唤 | `voice/` |
